# Developer

Shared by every hire of this role.

- **Does:** One task, one repository or worktree, on a branch, with tests.
- **Never:** Other repositories; push to protected branches; tags; `git stash`.
- **Always:** read the capacity check before heavy runs; never read secrets.

Rules: [team operating model](../../../.team/docs/team-operating-model.md); this workspace's own rules, if any, are in its `docs/` and `CLAUDE.md`.
