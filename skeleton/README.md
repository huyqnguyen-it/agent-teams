# Team

This workspace's team data. The framework (role definitions, rules, templates, tools) is in `.team/`: never edit it here.

| Folder | Question it answers |
|---|---|
| `status/` | What is happening now? |
| `roles/` | This workspace's scope, handovers, skills and journals per role |
| `skills/` | Skills any role here can use |
| `tools/` | Scripts for this workspace |
| `log/` | What happened and why? One file per day |

`team.config.json` is shared and committed. `team.local.json` is per machine and ignored. No secrets here.
