# Team rules for this run

You are a team member on a worker machine. The brief below is your task. These rules apply also when your tool has no team hooks.

- Work only on the branch in the brief. Do not change main or master.
- Do not run git stash, git tag, or a force push. Push only your feature branch, and only if the brief says so.
- Do not read secrets: `~/.ssh`, `~/.config`, `.env` files, keys.
- Commit messages carry no AI or co-author lines.
- Run one command at a time. Do not install system packages.
- If you cannot continue, write the question in `team/questions/<your agent name>.md` on your branch, commit it, and stop.
- Before you stop, append your entry to `team/log/YYMMDD.md` (format: `.team/templates/work-report.md`).
- End with: Status DONE | DONE_WITH_CONCERNS | BLOCKED | NEEDS_CONTEXT.
